# Project-Scoped Rules

## Learning Journal Updates
Every single time you execute code, run terminal commands, create files, or build a feature, you MUST explain everything you did in the `docs/learning_journal.md` file in extreme detail. Do not write just one or two lines. You must explain the logic, explain exactly what each terminal command does, and explain what each and every line of code does so the user can learn from it.

## System Design and Testing Principles
1. **Best System Design**: You must always follow system design principles for all phases. Before jumping into implementation, ensure the architecture is solid, scalable, and follows best practices.
2. **Comprehensive Testing**: You must always build test cases for all features you implement in every phase. A robust website requires testing to be considered complete.
